What ShiftIQ Does

The system turns disconnected sales, scheduling, and employee data into a coordinated operating assistant. It is designed for small food and retail businesses that need practical staffing decisions, not a generic chatbot.

Sales POS-style CSV data is analyzed by day, hour, item mix, and demand pattern.
Labor Schedules are evaluated against labor percentage targets and employee max-hour constraints.
Coverage Call-outs and dropped shifts are matched with qualified workers using availability, skills, and fairness.

Agent Team

ShiftIQ uses multiple focused agents/tools because scheduling requires different kinds of reasoning: explanation, optimization, live lookup, policy retrieval, and workflow execution.

Core Orchestrator

The main Manager Chat agent receives the user request, decides whether it needs data, tools, policy grounding, or approval, and coordinates the right workflow.

Intent routingDetermines whether the manager is asking for insight, schedule action, coverage help, or policy.
Tool coordinationCalls real ShiftIQ functions instead of relying only on model memory.
Approval awarenessHigh-impact changes create approval requests before being applied.

Specialists

Specialized capabilities keep answers grounded and operationally useful.

Schedule Explanation AgentExplains why employees were assigned or why roles are unfilled.
Call-Out Coverage AgentRanks backups by availability, role match, remaining hours, and fairness.
Labor Optimization AgentFinds overstaffed periods and suggests savings tied to labor targets.
Policy Knowledge AgentSearches custom policy docs for grounded scheduling and approval answers.

MCP Tool Protocol

The MCP server makes ShiftIQ's business functions available through a standard tool interface, which is a stronger architecture than hardcoding every agent directly to internal Python functions.

Operational Tools

Generate block or flexible schedules, fetch current schedule state, edit assignments, and explain schedule decisions.

Decision Tools

Calculate labor summary, inspect sales insights, optimize cost savings, and retrieve weather-aware staffing recommendations.

Context Tools

Look up employees, search policy knowledge, find backup candidates, and create report artifacts.
